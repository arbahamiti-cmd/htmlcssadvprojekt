# Fall Guide — Complete HTML/CSS project

Open `index.html` in your browser to view the website. Use the navigation menu to visit the other four pages.

All missing pictures have been added to the `images/` folder. They are self-contained, age-appropriate seasonal illustrations/visuals created for this project. The header background path in `css/style.css` has also been corrected. No internet connection is required to view the pictures.

## Project files
- `index.html` — Home page
- `books.html` — Books
- `halloween_outfits.html` — Halloween outfits
- `about us.html` — About page
- `contact.html` — Contact page
- `css/style.css` — Styles
- `images/` — All 18 pictures

To replace any picture, copy a new JPG into `images/` with the same filename.
